# Free Offline JPG & PNG to WebP Converter (.exe)

A fast, lightweight, and 100% secure desktop utility designed to batch convert and compress JPEG, JPG, and PNG images into modern WebP format right on your Windows machine without uploading files to any external server.

## 🚀 Key Features
- **100% Offline & Private:** Your images never leave your local computer.
- **Batch Processing:** Convert hundreds of images in seconds.
- **Flexible Compression:** Switch instantly between adjustable quality sliders (1-100%) and **Lossless Compression**.
- **Transparency Support:** Retains alpha transparency channels for PNG files seamlessly.
- **Portable & Standalone:** No complex installations or Python runtimes required—just drop the `.exe` and run.

---

## 📥 Download & Usage
1. Go to the **[Releases](../../releases)** tab on the right side of this repository.
2. Download the latest `converter.exe` file.
3. Place the `.exe` file inside any folder containing your target JPG/PNG images.
4. Run the app, select your compression settings, and click **Convert Images Now**. 
5. Your optimized WebP files will be neatly saved inside a newly created `webp_converted` folder.
